Streaming

A spec that arrives in pieces

A model streams one JSON Patch per line. The renderer applies each patch to an immutable snapshot and redraws. Children that have not arrived show a skeleton that holds the final layout.

    How it works

    Decode

    The decoder keeps the trailing partial line in a buffer. Complete lines become patches. A line that does not parse is journaled and skipped.

    Apply

    Each patch (add, replace, remove, move, copy, test) changes an immutable snapshot. An element that has no path from the root waits until its parent arrives.

    Draw

    The renderer redraws at most once per frame. A 180 ms fade shows new content, and none under Reduce Motion. Cancelling keeps the last snapshot.
