swift-json-render Planned

Spectacularly simple, highly customisable.

A native SwiftUI runtime for the json-render spec. A model writes a small flat JSON spec. Your app shows real macOS and iOS views. No web view, no JavaScript, no code in the spec.

What the package is

json-render defines a flat, streamable JSON grammar: a root id, elements by id, and state. swift-json-render reads that grammar and builds SwiftUI. The spec stays identical to upstream (core 0.22.0), so upstream prompts, skills and fixtures carry over.

Simple by default

Three to five props per component. One radius scale, one type scale, colour only for meaning. A card looks finished with no configuration.

Customisable in layers

Theme tokens, variants, style hooks, slots, view replacement, custom components. Customisation never changes what a spec means.

Streams and nests

Patches fill the card as they arrive. Missing children show skeletons. Cards nest to 64 levels, with repeats and scoped state.

Quick start Planned API

Nothing here is released yet. These names come from the plan and may change before the first alpha. The goal is a quick start under 20 lines.

import SwiftUI
import JSONRender

struct FailingTestsCard: View {
    let spec: Spec   // decoded from the model's JSON

    var body: some View {
        JSONRenderView(spec: spec, catalog: .standard)
            .jsonRenderTheme(.native)
    }
}
import SwiftUI
import JSONRender

struct StreamingCard: View {
    let chunks: AsyncStream<String>   // model output, any chunk size

    var body: some View {
        JSONRenderStreamView(chunks: chunks, mode: .jsonl, catalog: .standard)
            .jsonRenderTheme(.rafuIndigo)   // skeletons fill in as patches arrive
    }
}
// Package.swift
.package(url: "https://github.com/vatsalsaglani/swift-json-render", from: "0.22.0"),

// target dependencies
.product(name: "JSONRender", package: "swift-json-render"),
.product(name: "JSONRenderCharts", package: "swift-json-render"),   // optional
