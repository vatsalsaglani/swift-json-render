## Not upstream

The runtime does more than upstream in a few places. Each one is documented and tested on its own; none changes the meaning of a spec that upstream accepts.

- Built-in actions `toggleState` and `incrementState`. `PromptOptions(includeExtensions: false)` removes them from the prompt, so a spec can also run on the web.
- The `+` props: optional extras on top of upstream props (for example `Card.variant`, `Stack.wrap`, `Table.sortable`, `Button.size`). The prompt line equals upstream's once the extras are removed (`StandardCatalogPromptTests`).
- Slots beyond upstream's: the named slots of `Card`, `Dialog`, `Drawer`, `Image`, `Table` and the charts.
- Deviations where the Swift behaviour is safer: a `visible` shape the runtime cannot evaluate is hidden (upstream sometimes shows it); `pushState` with `$id` gives a UUID string; every action honours `confirm`; a pattern check that could take exponential time is refused with a neutral message.
- Whole modules with no upstream counterpart: the 15 charts, the streaming layer on a display link, the composer on the OpenAI Decisions API, and the style, theme and slot layers.
